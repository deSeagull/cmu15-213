各关卡推理过程
第一关：字符串比较
phase_1 调用 strings_not_equal，将输入与地址 0x402400 处的字符串比较。返回值为 0 时跳过爆炸函数，因此输入必须与目标字符串完全相同。使用 x/s 0x402400 查看，得到答案：
```typescript
Border relations with Canada have never been better.
```
第二关：数列关系
程序调用 read_six_numbers，将六个整数存入栈中。首先检查第一个数是否为 1，再循环比较当前数与前一个数的两倍是否相等。因此数列首项为 1，后续各项依次翻倍，答案为：
```
1 2 4 8 16 32
```
第三关：跳转表
程序读取两个整数，要求第一个数在 0～7 之间，并以它为下标查询地址 0x402470 处的跳转表。不同分支将不同常量写入 eax，最后检查第二个输入是否等于该常量。选择第一个数为 3 时，对应分支将 eax 设置为 0x100，即十进制 256，因此一组答案为：
```
3 256
```
第四关：递归查找
程序要求第一个数在 0～14 之间，并调用 func4(x, 0, 14)。该函数计算区间中点：目标小于中点时向左递归，返回结果乘 2；大于中点时向右递归，返回结果乘 2 加 1；等于中点时返回 0。
外层要求递归返回值和第二个输入均为 0。初始区间的中点为 7，输入 7 可直接返回 0，因此一组答案为：
```
7 0
```
第五关：位运算与字符映射
程序首先要求输入长度为 6，再对每个字符执行 & 0xF，取其编码的低四位作为下标，查询字符表 maduiersnfotvbyl。转换后的字符串必须为 flyers。
在表中，flyers 对应的下标依次为 9、15、14、5、6、7。选择低四位满足这些下标的字符，可得到一组答案：
```
ionefg
```
第六关：链表重排
程序要求输入六个互不相同、范围为 1～6 的整数，再将每个数替换为 7 - 原输入，按照转换后的数字选择原链表中的节点并重新连接。最后检查新链表中相邻节点的数值是否满足前者不小于后者。
原始六个节点的数值依次为 332、168、924、691、477、443。按数值从大到小排列，对应节点顺序为 3、4、5、6、1、2。考虑前面的转换，逐项用 7 减去节点位置，得到答案：
```
4 3 2 1 6 5
```
隐藏关：入口检查与二叉树递归
六个普通关卡通过后，phase_defused 使用 %d %d %s 重新解析第四行。若第三个字段为 DrEvil，则进入隐藏关。因此将第四行改为：
```
7 0 DrEvil
```
隐藏关读取一个整数，并要求 fun7 在二叉搜索树中查找该数后的返回值为 2。该函数找到目标时返回 0，向左递归返回结果乘 2，向右递归返回结果乘 2 加 1。
查找 22 的路径为 36 → 8 → 22，依次向左、向右。命中后返回 0，逐层回溯得到 2 × 0 + 1 = 1、2 × 1 = 2，满足要求，因此在答案文件第七行填写：
```
22
```
实验收获与感想
通过本实验，我对寄存器传参、栈上数据布局和条件跳转有了更清楚的理解，也学习了循环、跳转表、递归及链表在汇编中的实现方式。分析时，先定位爆炸调用，再反推通过条件，并用 GDB 检查寄存器和内存，可以逐步验证推理。实验也提醒我注意地址与内容、lea 与 mov、有符号与无符号比较的区别；这些细节往往决定对程序逻辑的理解是否正确。
