bitXor	用 ~x & ~y 找出两位都为 0 的位置，用 ~(x & y)排除两位都为 1 的位置。两者组合后，只留下不同的位。
tmin	将 1 左移 31 位，使最高位为 1、其余位为 0，得到最小的 32 位补码整数。
isTmax	令 a = x + 1，检查 a 是否等于自身的相反数。符合条件的有 0 和最小整数；再排除 a = 0，就只剩 x = Tmax。
allOddBits	用 0xAA 扩展出掩码 0xAAAAAAAA。检查 x 与掩码相与后是否仍等于掩码。
negate	按补码规则，取反后加 1 得到 -x。
isAsciiDigit	先检查高位部分是否为 0x3，再检查低四位是否在 0～9，从而限定在 0x30～0x39。
conditional	把 !!x 转成全 1 或全 0 的掩码，分别从 y、z 中选出需要的值。
isLessOrEqual	符号不同的时候直接根据 x、y 的符号判断；符号相同的时候，根据 y - x 的符号判断 x <= y。
logicalNeg	非零数与其相反数按位或后，最高位一定为 1；右移并加 1 后得到 0。输入为 0 时则得到 1。
howManyBits	逐级右移 16、8、4、2、1 位，定位与符号位不同的最高位。累计位置后再加上符号位，得到最少所需位数。
floatScale2	拆出符号、阶码和尾数。特殊值原样返回；非规格化数将尾数左移一位；规格化数将阶码加一。
floatFloat2Int	根据阶码算出实际指数，补上规格化数隐藏的前导 1，再通过移位取得整数部分；过小返回 0，超范围返回规定值。
floatPower2	根据 x 所在范围，分别构造非规格化数、规格化数、0 或正无穷的位表示。
